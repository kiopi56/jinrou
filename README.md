# 人狼（Safari ホーム画面アプリ）

5人前後で端末をひとつ回して遊ぶ人狼。ビルド不要、依存ライブラリなし。

## ファイル

```
index.html            本体（HTML + CSS + JS を1枚に同梱）
manifest.webmanifest  アプリ名・アイコン・全画面表示の指定
sw.js                 Service Worker（2回目以降はオフラインで起動）
icon-180.png          ホーム画面用（iOS）
icon-192.png / icon-512.png
```

## 置きかた（GitHub Pages）

1. リポジトリを作り、上記5ファイルをルートに置く
2. Settings → Pages → Source を `main` / `root` にする
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` を **iPhone の Safari** で開く

`file://` で開いても動きはしますが、ホーム画面追加も Service Worker も効きません。**https での配信が必須**です。

## ホーム画面に追加する

Safari で開く → 共有ボタン → 「ホーム画面に追加」→ 追加

以降はアイコンから起動し、アドレスバーなしの全画面で立ち上がります。
Chrome や他ブラウザからの追加ではブックマークになるだけなので、必ず Safari から。

## 更新するとき

ファイルを差し替えたら `sw.js` の1行目を `jinrou-v2`、`v3` … と上げてください。
上げないと古いキャッシュが残り、更新が反映されません。

## 仕様

- 役職札と占い結果は**長押ししている間だけ**表示（渡すときの事故防止）
- 夜は役職持ちだけでなく**生存者全員**に順番に回る（誰が役職持ちか漏らさないため）
- 進行状況は端末内に自動保存。アプリが落ちても開き直せば途中から続く
- 「履歴」からは消えないので、新しく始めたいときは結果画面の「設定を変える」から

## 既知の制約

- 画面スリープ防止（Wake Lock）は iOS 16.4 以降のみ。それ以前は自分で自動ロックを切ってください
- 保存はその端末のみ。Safari の「履歴とWebサイトデータを消去」で消えます
- プライベートブラウズでは保存が効きません（動作はします）
